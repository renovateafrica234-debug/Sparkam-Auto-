# Sparkam Auto-Publisher ⚡️

> Production-ready One-Tap Instagram Business Publisher and CRM for **ZEE ZAIN, Abuja** (WAT = Africa/Lagos, UTC+1).
> Eliminates copy-pasting for scheduled Instagram campaigns across `@sparkam.media` and `@zeeteroliver`.

---

## 🚀 Key Features

1. **One-Tap Instant Publish (No Copy-Paste)**:
   - Publishes directly to Instagram Business accounts via Facebook Graph API v20.0 with single button click `[APPROVE & POST TO IG NOW]`.
   - Supports **Single Image**, **Multi-slide Carousel**, and **Reels (Video)**.
2. **Meta AI Webhook Receiver**:
   - `POST /api/hooks/scheduled-post` receives scheduled post payloads generated by Meta AI recurring tasks.
   - `GET /api/hooks/scheduled-post?test=1` outputs sample schema for webhook setup.
3. **Tonight's Queue (Abuja WAT)**:
   - **Daily 6:00 PM WAT (17:00 UTC)**: 4-part 27-point Abuja Website Checklist thread for `@zeeteroliver`.
   - **Daily 8:00 PM WAT (19:00 UTC)**: 48hr AI Business Launch System Macro Reel (₦35k) for `@sparkam.media`.
   - Live WAT countdown timers with Auto-Publish toggles.
4. **CRM & Google Sheet Integration**:
   - Synchronizes with Google Sheet `1BGO3RB...` (Waitlist & Paystack Fulfilled payments, including ₦100 tests and ₦35,000 launch packages).
5. **Vercel Cron Automation**:
   - Pre-configured `vercel.json` running `/api/cron/daily-publisher` every hour (`0 * * * *`).
   - Automatically detects due posts and fires publish without human intervention if Auto-Publish is toggled ON.
6. **Drift Bami EP2 Folder**:
   - Built-in Zuma Rock climbing challenge content ready to queue for weekend runs.

## 🔑 How to Get Long-Lived Instagram Graph API Tokens

Follow these official Meta Developer steps to obtain tokens for `@sparkam.media` and `@zeeteroliver`:

### Step 1: Meta Developer Account & App Creation
1. Go to [developers.facebook.com](https://developers.facebook.com) and log in.
2. Click **My Apps** > **Create App**.
3. Select **Other** > **Business** as the app type.
4. Name it `Sparkam Auto-Publisher` and link your Meta Business Account.

### Step 2: Ensure Instagram Business Account is Linked
1. Open Facebook, go to your Page (e.g. Sparkam Media).
2. Go to **Settings & Privacy** > **Settings** > **Linked Accounts** > **Instagram**.
3. Connect your Instagram Professional/Business account (`@sparkam.media` or `@zeeteroliver`).

### Step 3: Graph API Explorer & Scopes
1. Go to the [Graph API Explorer](https://developers.facebook.com/tools/explorer/).
2. Select your Meta App in the dropdown.
3. In **User or Page**, select **User Token**.
4. Add the following permissions:
   - `instagram_basic`
   - `instagram_content_publish`
   - `pages_read_engagement`
   - `pages_show_list`
   - `business_management`
5. Click **Generate Access Token** and approve the Facebook pop-up dialog.

### Step 4: Get Your Instagram Business User ID
Run this query in Graph API Explorer:
```http
GET /v20.0/me/accounts?fields=name,id,instagram_business_account{id,username}
```
This returns:
```json
{
  "data": [
    {
      "name": "Sparkam Media",
      "id": "YOUR_FB_PAGE_ID",
      "instagram_business_account": {
        "id": "17841409823471011",
        "username": "sparkam.media"
      }
    }
  ]
}
```
- Copy `instagram_business_account.id` to `IG_USER_ID_SPARKAM` (or `IG_USER_ID_ZEETER`).

### Step 5: Convert to a 60-Day or Never-Expiring Long-Lived Token
1. Open the [Access Token Debugger](https://developers.facebook.com/tools/debug/accesstoken/).
2. Paste the user token from Step 3 and click **Debug**.
3. Click **Extend Access Token** at the bottom to get a 60-day token.
4. To get a never-expiring Page token:
   Query:
   ```http
   GET /v20.0/{page-id}?fields=access_token&access_token={long-lived-user-token}
   ```
5. Save the resulting token in your environment as `IG_TOKEN_SPARKAM` or `IG_TOKEN_ZEETER`.

## 🤖 Meta AI Webhook Integration

Configure your Meta AI scheduler tasks to POST directly to:
```http
POST https://your-domain.vercel.app/api/hooks/scheduled-post
Content-Type: application/json

{
  "account": "zeeteroliver",
  "type": "thread",
  "caption": "Developers charge ₦200k-₦500k in Abuja...",
  "image_urls": [
    "https://images.unsplash.com/photo-1460925895917-afdab827c52f?w=1200&auto=format&fit=crop&q=80"
  ],
  "scheduled_for": "2026-09-12T17:00:00.000Z",
  "cta": "Comment CHECKLIST"
}
```

The payload will immediately appear in **Tonight's Queue** with one-tap approval!
